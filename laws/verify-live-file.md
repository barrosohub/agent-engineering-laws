# Verify the live file, not a cached context snapshot

When judging a docs-as-contract question, or accusing anyone of a convention violation,
verify against the **live file on disk**.

## Never cite

- A snapshot of an instruction file that was injected into your context at session start.
- A rule you remember from an earlier session.
- A file another agent quoted to you.
- Your own summary of a file you read many turns ago.

Instruction files change. Rules get amended. The version in your context may be stale by
hours or by an unmerged edit.

## Always do

1. Read the live file with your Read tool, now.
2. Cite the **live line** — path plus line number plus the quoted text.
3. If the live file contradicts your memory, the live file wins and you say so.

An accusation without a live citation is noise, and it costs the other party real time to
disprove.
